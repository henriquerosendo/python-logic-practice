# 🐍 Treinando Lógica com Python

Este repositório contém uma série de exercícios desenvolvidos para **reforçar os fundamentos de lógica de programação com Python**, servindo como **aquecimento para estudos em PySpark** e manipulação de dados em larga escala.

---

## 🎯 Objetivo

Antes de iniciar projetos com **Apache Spark / PySpark**, decidi revisar e praticar conceitos essenciais de **lógica e programação funcional**, garantindo uma base sólida para trabalhar com transformações de dados, funções e estruturas de controle.

---

## 📚 Estrutura dos Exercícios

### 🧩 Etapa 1 — Fundamentos de Lógica em Python
Exercícios voltados para o raciocínio lógico e controle de fluxo:

1. **Par ou Ímpar** → uso de `if/else` e laços `while`  
2. **Soma de lista** → iteração e acumulação manual de valores  
3. **Contagem de vogais** → percorrendo strings e filtrando caracteres  
4. **Maior e menor número** → comparações sem uso de funções prontas  
5. **Dicionário de notas** → uso de `dict` e iteração com `.items()`

---

### ⚙️ Etapa 2 — Lógica Funcional e Pensamento Spark

Exercícios inspirados nas transformações que o **PySpark** realiza internamente, utilizando funções de ordem superior:

1. **Função com retorno (`def`)**  
2. **Transformações com `map()`**  
3. **Filtragem com `filter()`**  
4. **Agregação com `reduce()`**  
5. **Mini ETL com listas e dicionários**

🔹 **Desafio bônus:**  
Simulação de um pequeno pipeline ETL — aumento de preços, filtragem e cálculo total usando `map()`, `filter()` e `reduce()`.

---

## 🚀 Tecnologias Utilizadas

- **Python 3.x**
- Conceitos de:
  - Programação Estruturada
  - Programação Funcional
  - Estruturas de Dados (`list`, `dict`)
  - Funções de Alta Ordem (`map`, `filter`, `reduce`)
